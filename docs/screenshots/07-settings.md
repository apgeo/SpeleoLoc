# Settings

[← Screenshot index](README.md) · [← Wiki index](../README.md)

The settings tree that governs codes, maps, images, sync and the database.

> The app runs in **Romanian** by default, so the screenshots show Romanian labels. Each entry lists the on-screen wording next to its English equivalent.

**On this page:** [The settings list, top](#settings-main-top) · [The settings list, bottom](#settings-main-bottom) · [The whole settings list](#settings-main-full)

<a id="settings-main-top"></a>

## The settings list, top

![The settings list, top](../images/settings-main-top.jpg)

*Top of the Settings list, from General down to Database.*

The main Settings screen lists every configuration area as a tappable row with a one-line summary of what it controls. This capture shows the top of the list: General, Image compression, QR Code Generation, Place code identifiers, PDF Output, Map and Database. Tapping any row opens that area's own settings subpage; the overflow button in the app bar opens the global app menu.

<details><summary>On-screen wording (Romanian → English)</summary>

- Setări — Settings (app bar title)
- General — General / Limba și preferințe generale — Language and general preferences
- Compresie imagini — Image compression / Comprimă și redimensionează imaginile la import — Compress and resize images on import
- Generare grafică cod QR — QR Code Generation / Dimensiune QR, culori, corecția erorilor — QR code size, colors, error correction
- Identificatori cod loc — Place code identifiers / Strategie, reguli și mod generare pentru codurile locurilor din peșteri și coduri QR — Strategy, rules, and QCRI mode for cave place codes
- Ieșire PDF — PDF Output / Aranjare grilă, șablon etichetă — Grid layout, label template
- Hartă — Map / Straturile hărții de suprafață și fișierele MBTiles offline — Surface map layers and offline MBTiles files
- Baza de date — Database / Reinițializare, export baza de date — Reinitialize, export database
- Back arrow and three-dot overflow menu in the app bar

</details>

## The settings list, bottom

![The settings list, bottom](../images/settings-main-bottom.jpg)

*Settings scrolled down to the data-sharing and beacon entries.*

The same Settings screen scrolled to its lower half, where the data-sharing and hardware entries live. From here the user opens Map, Database, Users, Man. sync (archive-file exchange with other devices), FTP / SFTP sync, Data Export / Import, and Beacon detection. Beacon detection is the last row of the list in a release build; a Debug info row appears below it only when debug mode is on.

<details><summary>On-screen wording (Romanian → English)</summary>

- Setări — Settings (app bar title)
- Hartă — Map / Straturile hărții de suprafață și fișierele MBTiles offline — Surface map layers and offline MBTiles files
- Baza de date — Database / Reinițializare, export baza de date — Reinitialize, export database
- Utilizatori — Users / Gestionează utilizatorii și selectează utilizatorul curent — Manage users and select the current one
- Sinc. man. — Man. sync / Schimbă date cu alte dispozitive prin fișiere arhivă — Exchange data with other devices via archive files
- Sincronizare FTP / SFTP — FTP / SFTP sync / Sincronizează printr-un server FTP sau SFTP partajat — Sync with a shared FTP or SFTP server
- Export / Import Date — Data Export / Import / Exportă sau importă toate datele aplicației — Export or import all application data
- Detectare beaconuri — Beacon detection / Detectare automată a locurilor prin beaconuri BLE, praguri, diagnostic — Automatic place detection via BLE beacons, thresholds, diagnostics

</details>

## The whole settings list

![The whole settings list](../images/settings-main-full.jpg)

*The complete Settings menu, all twelve categories in one capture.*

A full-height scrolling capture of the Settings screen showing every category at once, in the order the app presents them: General, Image compression, QR Code Generation, Place code identifiers, PDF Output, Map, Database, Users, Man. sync, FTP / SFTP sync, Data Export / Import and Beacon detection. Each row carries an icon, a title and a one-line description of what that subpage configures, and a chevron indicating it opens a further screen. This is the best single image for an overview of where each setting lives.
