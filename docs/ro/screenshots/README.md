# Galerie de capturi de ecran

[← Înapoi la cuprins](../README.md)

Fiecare captură de ecran din acest wiki se află aici, grupată pe zone, cu o
descriere a ceea ce face ecranul și a ceea ce se vede pe el. Paginile de
funcții trimit către aceste galerii în loc să repete imaginile, așa că un
ecran este descris o singură dată și este referit de oriunde este relevant.

> **Capturile de ecran arată interfața în limba română.** Româna este limba
> implicită a SpeleoLoc (engleza se alege din **Setări → General → Limba
> aplicației**), iar aplicația a fost fotografiată așa cum este livrată.
> Fiecare intrare de mai jos scrie formularea românească de pe ecran alături
> de echivalentul ei în engleză, folosit în restul acestui wiki.

**42 de capturi de ecran** în total, făcute pe un telefon în orientare
portret.

## Convenții

- Imaginile sunt păstrate o singură dată în [`docs/images/`](../../images/) și
  sunt folosite în comun de edițiile în engleză și în română ale acestui wiki.
- Numele fișierelor sunt slug-uri stabile (`cave-map-measure-distance.jpg`),
  nu momente ale capturii, așa că un link rămâne valid atunci când o captură
  este refăcută.
- Barele de stare și barele de navigare ale telefonului sunt decupate; nimic
  din interiorul ferestrei aplicației nu este retușat.

Vedeți [Contribuții la acest wiki](../contributing-docs.md) pentru felul în
care se adaugă sau se înlocuiește o captură de ecran.
